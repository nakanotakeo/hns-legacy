h14m.org 標準ユーザ変数

2002/01/24

hns では，毎日記述する項目をユーザ変数として自由に定義できます．しかし， 同一内容を表すユーザ変数が複数表現されると，互換性の問題が生じます． この問題に対応するため，h14m.org としてユーザ変数を標準化しています．

新しいユーザ変数をご利用の場合は，当プロジェクトまでお知らせください． 標準として定義していきます． またユーザ変数を利用される場合は，ここで定められている変数名を 使われることを 推奨いたします．

変数名 英語表記     意味                表記例      
TENKI  WEATHER      天気                晴れ,曇り,雨
BASHO  LOCATION     天気の観測場所      六甲,南京町 
TAIJU  WEIGHT       体重                50.2
TAION  TEMPERATURE  体温                36.7
SUIMIN SLEEP        睡眠時間            8.5
BGM    BGM          BGM                 Kiroro/未来へ
HOSU   STEP         歩いた歩数          6851
HON    BOOK         読んだ本            ラブひな8巻
KITAKU HOMECOMING   帰宅時間            18:03
WALK   WALK         歩いた時間          50分,1時間20分
RUN    RUN          ジョギングした時間  50分,1時間20分
YOTEI  SCHEDULE     予定                粗大ごみの日
