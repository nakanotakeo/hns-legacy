ハイパー日記システム Version 2.20

hns-2.20 の新機能

  • 簡単な表の記述 [業界初]
    RTコマンドの採用により簡易な表(table)の記述が可能になりました。
  • 特定カテゴリ表示
    特定のカテゴリのみを表示可能になりました。
  • リンク拡張機能
    オンライン書店での ISBN コード検索へのリンク、 オンライン CD ショップ で CD 品番検索へのリンク、 MLアーカイブなど決まった形式の URL をあらかじめ定義することで、 簡単にリンクを張ることができます。
  • ヘッドラインを表示する headline.cgi
    日記のヘッドラインを表示する headline.cgi が追加されました。
  • カレンダからの厳密なリンク
    日記が存在しない月へは、リンクしないようになりました(設定可能)。
  • 強化された日記の静的生成
    動的生成用のテンプレートと静的生成用のテンプレートを分離可能に。
  • UTF8 でエンコードされる検索キーワード抽出
    Jcode.pm がインストールされている場合、一部の検索エンジンから送られる、 UTF8 でエンコードされた参照元情報をデコードして、検索キーワードを 文字化けせずに抽出可能になりました。
  • 日記と連動した掲示板
    日記と連動した掲示板の機能が追加されました。 これにより、日記読者とのコミュニケーションがより綿密になることが 期待できます。
  • RSS を生成する rss.cgi
    日記の RSS (RDF Site Summary) を生成する rss.cgi が追加されました。
