ハイパー日記システム Version 2.20

hns-2.10-pl1 からの仕様変更

仕様変更

  • テンプレート仕様(テーマ仕様)の変更
    テーマでカスタマイズ可能な、テンプレートの仕様が変更されています。 テーマjapanese の 変更点 を参考に、必要な修正を行ってください。
    • theme-static.ph は不要になりました。 静的生成と動的生成のテンプレートが分離されたため、theme.ph に動的生成用のテンプレート({dynamic})と 静的生成用のテンプレート({static})の両方の記述が可能になりました。
    • テンプレート中でのカレンダの日付は、%day から %calendar_day に 変更されました。package HNS::Calendar::Table; および package HNS::Calendar::NoTable; は、以下のように変更してください。 
      $DayCurrentTemplate = qq(<a href="%ruri#%{ymd}0">%calendar_day</a>);
$DayNonCurrentTemplate = qq(<a href="%href">%calendar_day</a>);
      この仕様変更により、hns-2.19.3 対応でない、過去のテーマを使う場合、上記の 修正を行わない限り、正しくカレンダからのリンクが張れません。
  • hnf の配置の変更(互換性の廃止)
    ~/diary/ に hnf を置く方法は、廃止されました。 hnf は，日記ディレクトリ(~/diary/)以下に年別のディレクトリを作成し置きます． ~/diary/2002/ には， 2002年の hnf を置きます。
  • 1セクション表示の場合、HTMLのタイトルにセクション・タイトルを 表示するように変更されました(2.19.6)。
