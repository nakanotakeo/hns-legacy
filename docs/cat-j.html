日記のカテゴリ分類の方法

日記のカテゴリ分類とは?

日記を内容に応じて，セクション毎に分類したい場合があります． 例えば，「FreeBSDのこと」「Linuxのこと」「マジカルとこちゃんのこと」 と 3つの分類を考えます．
この場合に，ハイパー日記システムでは，以下のことが可能です。

  • 日記の表示時に、特定のカテゴリのみを表示することができます。
  • 日記のセクション・タイトル (NEWコマンド) にそれぞれ内容を表すアイコンを表示することができます．
  • カテゴリ別に日記のセクション・タイトルを 表示することができます．
  • Namazu for hns での検索時に カテゴリ名による検索をすることが可能になります．

カテゴリ分類の利用方法

まずカテゴリ名を決めます．あとから追加することも可能です． 例えば，上記の例では，「FreeBSDのこと」を freebsd， 「Linuxのこと」を linux，「マジカルとこちゃんのこと」を とこちゃん と決めます．
この場合，hnf では，NEW, LNEW または RLNEWコマンドの直前に，

CAT freebsd
NEW 謎ブラウザのインストール

のように記述します．1つの NEW(LNEW,RLNEW) にカテゴリは複数指定可能です． その場合は，スペースでカテゴリ名を区切って下さい． 必然的にカテゴリ名にスペースは使えません．

特定のカテゴリのみを表示する方法

日記URLが http://www.example.ne.jp/~hoge/diary/ の場合、 http://www.example.ne.jp/~hoge/diary/?CAT=freebsd にアクセスすることで、freebsdカテゴリの内容のみを表示することが可能です。
また、 http://www.example.ne.jp/~hoge/diary/?CAT=freebsd&CAT=linux にアクセスすることで，freebsdカテゴリとlinuxカテゴリの内容を同時に表示する こともできます。3つ以上のカテゴリを表示したい場合も同様です．

カテゴリ別にアイコンを表示する方法

  1. カテゴリ別にアイコンを表示するには，アイコンを用意する必要が あります． アイコンは ~/public_html/diary/cat/ に置きます．
  2. 設定ファイルcat.txt を記述します．~/public_html/diary/cat/cat.txt に
    カテゴリ名[スペース]アイコン・ファイル
    と記述します． 
    freebsd freebsd.png
linux linux.png
とこちゃん toko.png
    なお、アイコンがない場合は、 
    freebsd freebsd.png
linux linux.png
とこちゃん
    のようにカテゴリ名だけを記載することもできます。cat.txt に 記載されたカテゴリ名は、「タイトル一覧」表示フォーム(標準では 日記の後、フッタ(foot.txt)の前に表示されます)のカテゴリ指定に 表示されます。
