ハイパー日記システムの特徴

  • 日記作成を強力にサポート
    hns では，HTML より 256倍(当プロジェクト比)簡単な hnf(Hyper Nikki File) を記述するだけで，自動的に (だいたい) 正しい HTMLドキュメントが生成されます．HTML を全く知らない初心者の方でも (だいたい) 正しい ウェブ日記が簡単に書けます．
    以下のようなコマンドが使用できます(抜粋)．
    • NEW
    • SUB
    • URL
    • LINK
    • IMG
    • UL/OL & LI
    • PRE
    • CITE
  • 日記の TCO(総保有コスト) を大幅に削減
    hns では，日々 hnf を記述するだけで，あとはシステムが自動的に HTML にして表示してくれます．このため、現代ウェブ日記に必要な 日付やタイトルへのリンク/アンカー，日記の一定期間毎の整理など から完全に解放されます．
    HTML の作成に比べ hnf は作成コストは大幅に低く済みます (最大99.89％の削減．当プロジェクト推計)．
  • FreeBSD/Linux など多数の OS での稼働実績
    主要OS である FreeBSD および Linux での豊富な稼動実績 があり，また，他の Un*x でも動作しています。動作報告は、 ハイパー日記システムのインストール を 御覧願います。動作確認済みのプロバイダなどは 動作確認されたプロバイダなどの一覧 をご覧願います。
  • 強力なアクセス・ログ機能 [業界初]
    hns自身が強力なアクセス・ログ機能を持っています． 日記にどこからリンクされているかも わかり日記チェーンの分析に有用な情報を提供します． クッキーにより読者の追跡も標準で提供されます． また， 強力な アクセス解析プログラム も 標準で提供されています．
  • 豊富な日記更新方法
    日記を更新する方法は、
    • hnf をサーバ上でエディタで記述
    • hnf をサーバへ ftp などで転送
    • メールによる日記の更新
      モバイル環境からも簡単に日記更新ができます。
    • ウエッブからの更新
    といった方法があり、また Emacs用の mode や Jedit用マクロなど様々な 支援ツールが存在します。
  • Namazu for hns による全文検索 [業界初] (Namazu の動作環境が必要)
    hns用の Namazu for hns がリリースされており， これにより日記の全文検索を簡単に行うことが可能です． 検索猿人は Namazuそのものですので，100年以上の日記も一瞬で 検索できます．
  • 朝日奈アンテナ対応 [業界初]
    業界標準の 朝日奈アンテナ に完全対応．「ちょださー」に辱められることももうありません。
  • Lynx 完全対応 [業界初]
    業界標準のテキスト・ブラウザLynx に完全に対応しています．
  • テーマ機能 [業界初]
    日記のアピアランス(見ため; スタイル，背景，文字色など) を「テーマ」として定義でき， またあらかじめ用意されている「テーマ」を指定することで， 日記のアピアランス(見ため)を簡単に変更できます．
  • 非常に高速
    動的システム(静的システムとしても利用可能)ですが、非常に高速です。 1か月分の日記を表示するのにかかる時間(サーバの処理時間)は、Celeron 650MHz のマシンで 0.9秒程度(キャッシュを使わない場合は 2.8秒程度)、 PentiumII 400MHz のマシンで 1.4秒程度 (いずれも当プロジェクト計測)です(デフォルト設定の場合)。
