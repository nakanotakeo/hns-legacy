サーバ負荷について

ハイパー日記システムは，動的な日記システムです． アクセスがある度に HTMLファイルを hnf より自動生成して ユーザに送ります． このため，静的に HTMLファイルをあらかじめ用意する場合に 比較して，サーバの

  • CPUパワー
  • メモリ

をより多く消費します．

サーバ資源が不足している場合は，サーバの他の利用者に 多くの迷惑を掛ける場合があります．そのような場合は， サーバ管理者の指示に従って下さい．hns のテーマを設定することで 動的な HTML 生成をせずに，hns を静的システムとして 利用することも可能です(日記の静的生成参照)．

なお，ウェブ・ページをたち上げ公開すると，

  • サーバのCPUパワー
  • サーバのメモリ
  • サーバのハード・ディスク
  • ネットワーク帯域

などを消費します．これらの資源は通常全て他の人と共有されており 自分がこれらの資源を利用することは絶えず他の人の資源利用の可能性を 排除していることを意味します．これは静的動的いずれの場合にも 当てはまります．
