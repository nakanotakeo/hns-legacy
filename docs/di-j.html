更新時刻情報の提供について

hns には更新時刻情報を高速に提供する di.cgi が 附属しています。di.cgi は日記URL を http://www.example.ne.jp/~hoge/diary/ と すると http://www.example.ne.jp/~hoge/diary/di.cgi にインストールされます。

di.cgi は絶えず正しい日記の更新時刻情報を提供します。 アンテナから更新時刻を取得する場合は、日記本体ではなく di.cgi から更新時刻情報を取得することをお奨めします。

di.cgi は更新時刻以外にも、日記のタイトルおよび著者名なども提供します。

hns-2.20からは、HEADリクエストでも日記のタイトルを取得することが 可能になりました。これは、HTTPのTitle:へッダによって提供されます (see: RFC1945)。
